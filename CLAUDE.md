# Instrucciones del proyecto

Lee este archivo y `README.md` antes de modificar el proyecto.

- Implementa el sitio dentro de este directorio. No trabajes sobre la raíz de `Desarrollos Z` ni sobre otros proyectos.
- Usa las fotografías de `assets/images/` como recursos locales. No muevas ni borres los originales que el propietario dejó en la raíz del workspace.
- Usa el logotipo local si encaja con la propuesta. No sustituyas fotografías por imágenes genéricas.
- No inventes productos, categorías, precios, historia, testimonios, teléfono, WhatsApp ni enlaces sociales. Los datos no confirmados deben quedar editables y no presentarse como hechos.
- Evita identificar o promocionar personajes/marcas protegidas que aparezcan en las fotos salvo que el propietario confirme que tiene autorización. Prefiere imágenes de creaciones originales para las áreas destacadas.
- No crees enlaces de contacto que parezcan funcionales si falta el destino real. El enlace de Facebook proporcionado es `https://www.facebook.com/jaz.jaz.crochet/`.
- Mantén el alcance en el sitio web, accesibilidad, responsividad, SEO básico y pruebas locales. No despliegues, publiques ni hagas push.
